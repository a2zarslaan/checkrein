# Corrections log

### Pattern [frontend, mobile]: Page links break when a page title changes.

**What went wrong:** Links were stored by title.

**Correct approach:** Store links by page id.

**Rule:** Never key a link on a value people can edit.

**Files affected:** none

### Convention [process]: Every page edit records its author.

**What went wrong:** Edits could not be attributed.

**Rule:** Record the author on every edit.

### Lesson: headings that do not follow the grammar fail.

**What went wrong:** The heading names neither Pattern nor Convention.

**Correct approach:** Use one of the two heading forms.

**Rule:** Every rule heading follows the grammar.

**Files affected:** none
